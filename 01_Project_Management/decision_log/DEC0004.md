## UD reference

`UD04` — *"Exact class inventory, clinical definitions, labelability, overlap and target granularity"* (`01_Project_Management/decisions.csv` row `DEC0004`, blocks **`STEP-015 / G05`**).

## question

Which exact dental object and abnormality classes, radiographic visibility definitions, bounding-box granularities (focal lesion vs whole-tooth), rare/unsupportable class exclusions, and cross-cohort harmonization bridges (`HC01–HC05`) are approved across `DS0001–DS0006` (`Tracks A–F`)?

## report facts and locators

- Deleted report facts preserved in `OS §1.3` (`RF09`): Figure 1 lists *teeth, impacted tooth, cavities, lesions, restorations* as illustrative target examples on `2D OPG` images, without preassigning numeric class IDs, tooth-numbering schemes, or exhaustive class tables (`OS §6.1`).

## planning options and evidence (`STEP-013` & `STEP-014` Forensic Audit)

Across all `6` approved `G04 PASS` datasets (`7,789` active OPGs, `44,251` raw annotations), `STEP-014` (`04_Annotations/classes.csv` and `04_Annotations/protocols/class_definitions.md`) evaluated every source class against `2D OPG` visibility, box granularity, and statistical support:

1. **Option 1 (Keep all raw classes unmodified, including `DS0001 Class 11 Root resorption [N=5]` and `DS0006 z Smile Zone ROI`, or pool across datasets):**
   - *Rejected:* `DS0001 Class 11` has only `5` boxes in `internal_train` and `0` in `valid/test/external` (impossible to evaluate), `DS0006 z` is a cropping ROI frame rather than an object class, and pooling `DS0003` (`Healthy Teeth` boxed) with `DS0001/0002/0005` (`Healthy Teeth` unannotated background) corrupts training gradients (`OS §6.2 #4`).
2. **Option 2 (Aggressive pruning to only 3–4 common classes across all datasets):**
   - *Rejected:* Throws away `DS0001`'s rich `13`-class restorative/endodontic/surgical benchmark (`24,883` boxes), `DS0004`'s ordinal `PAI 3–5` severity grading (`6,741` boxes), and `DS0006`'s proximal vs occlusal pediatric caries distinction (`895` boxes).
3. **Option 3 (Recommended `STEP-014` Proposal — Track-Specific Native Schemas `Tracks A–F` + `5` Granularity-Matched Cross-Cohort Bridges `HC01–HC05`):**
   - **Track A (`DS0001 UMFIH`):** `13` active classes (`TrackA:0..12`: `Implant, Prosthetic restoration, Obturation, Endodontic treatment, Carious lesion, Bone resorption, Impacted tooth, Apical periodontitis, Root fragment, Furcation lesion, Apical surgery, Orthodontic device, Surgical device`), excluding `CLS0012 Root resorption (N=5)` and dropping `3` zero-area boxes.
   - **Track B (`DS0002 DENTEX`):** `4` active classes (`TrackB:0..3`: `Impacted [604], Caries [2,189], Periapical Lesion [158], Deep Caries [578]`) + auxiliary pooled `Any Caries` evaluation.
   - **Track C (`DS0003 Rahman Dhaka`):** `6` whole-tooth classes verified via SHA-256 bijection (`TrackC:0..5`: `0=Caries [194], 1=Infection [37], 2=Impacted Teeth [196], 3=Fractured Teeth [14], 4=BDC/BDR [97], 5=Healthy Teeth [651]`), evaluated both as `5-class pathology (0..4)` and `6-class (0..5)` with low-support caveat on `Fractured Teeth (N=14)`.
   - **Track D (`DS0004 Do 2024 Hanoi`):** `3` focal apical severity classes (`TrackD:0..2`: `PAI 3 [4,277], PAI 4 [1,755], PAI 5 [709]`) + pooled `PAI 3–5` apical lesion view.
   - **Track E (`DS0005 AU-OPG`):** `6` adult tooth classes converted deterministically `OBB -> AABB` (`TrackE:0..5`: `Filled [2,857], Crowned [1,377], Retained Root [941], Cavitated [815], Implant [544], Impacted [472]`).
   - **Track F (`DS0006 MD-OPG`):** `2` pediatric caries classes converted from polygons to tight `AABB` (`TrackF:0..1`: `Proximal Caries p [716], Occlusal Caries o [179]`), excluding `CLS0036 Smile Zone z` from object classes and dropping `1` zero-area polygon.
   - **Cross-Cohort Evaluation Bridges (`HC01–HC05`, `CLS0037–CLS0041`):** `HC01 Caries`, `HC02 Periapical Lesion`, `HC03 Impacted Tooth`, `HC04 Residual Root/BDC`, `HC05 Dental Implant`, strictly matching focal-lesion vs whole-tooth box granularity.

## recommendation and rejected alternatives

Adopt **Option 3** (`CLS0001–CLS0041` as specified in `04_Annotations/classes.csv` and `04_Annotations/protocols/class_definitions.md`).
