## UD reference

`UD05` — *"Annotation tool, native/export format, coordinate convention and box geometry"* (`01_Project_Management/decisions.csv` row `DEC0005`, required for **`G05 / STEP-015`**).

## question

What authoritative coordinate convention, native-to-export conversion rules across our `5` heterogeneous source formats (`YOLO .txt`, `COCO .json`, `Pascal VOC .xml`, `Label Studio OBB .csv`, `LabelMe Polygon .json`), degenerate-box filters, and round-trip accuracy tolerances are approved for `STEP-015`–`021`?

## report facts and locators

- Deleted report facts preserved in `OS §1.3` and `§6.2`: The project specifies `2D OPG` object detection using YOLO (`O1–O3`), without mandating a specific text precision, coordinate origin, or conversion formula for rotated/polygonal secondary datasets (`UD05`).

## planning options and evidence (`STEP-015` Round-Trip Verification)

1. **Option 1 (Modify/overwrite source annotation files in place):**
   - *Strictly Rejected (`OS §6.2`):* Destroys native provenance (`OBB` angles in `DS0005`, polygon vertices in `DS0006`, quadrant/FDI IDs in `DS0002`).
2. **Option 2 (Train separate detectors on rotated OBBs, polygons, and AABBs):**
   - *Rejected:* Violates `scope.md v1.0.0` (`G01 PASS`, standard `2D OPG` bounding-box detection only) and prevents unified evaluator comparison (`OS §7.2`).
3. **Option 3 (Adopted — Immutable Native Retention + Deterministic Canonical `AABB` Export via `src/opg/annotation_schema.py`):**
   - Retain all native annotations untouched in `03_Datasets/raw/DS0001–DS0006/`.
   - Convert all `6` datasets deterministically to canonical normalized axis-aligned bounding boxes (`<TrackIndex> <xc> <yc> <w> <h>` in `[0, 1]`, 6 decimal places, top-left `(0,0)` pixel origin):
     - `DS0001` (`UMFIH`): Exclude `source_id=11` (`Root resorption`, `N=5`), remap `12->11, 13->12`, drop `3` zero-area boxes (`max round-trip error = 0.000000 px`).
     - `DS0002` (`DENTEX`): Convert COCO `[x, y, w, h]` (`categories_3`) to `AABB` (`max round-trip error = 0.001904 px`).
     - `DS0003` (`Rahman Dhaka`): Preserve verified `0..5` whole-tooth `AABB`s (`max round-trip error = 0.000000 px`); quarantine unlabeled `DS0003_IMG_001202`.
     - `DS0004` (`Do Hanoi`): Convert Pascal VOC XML `<bndbox>` (`3/4/5` -> `0/1/2`) to `AABB` (`max round-trip error = 0.000260 px`).
     - `DS0005` (`AU-OPG`): Convert Label Studio percentage `OBB (x%, y%, w%, h%, rotation_deg)` clockwise around top-left `(px, py)` to tight enclosing `AABB` clipped to `[0, W]×[0, H]` (`max round-trip error = 0.000367 px`).
     - `DS0006` (`MD-OPG`): Convert LabelMe caries polygons (`p->0, o->1`) to tight enclosing `AABB` (`max round-trip error = 0.001030 px`), drop `1` zero-area shape, and exclude `z` (`Smile Zone` ROI) from object classes.

## recommendation and rejected alternatives

Adopt **Option 3** (`annotation_protocol_v1.0.0.md` & `src/opg/annotation_schema.py`).
