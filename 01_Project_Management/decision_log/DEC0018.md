## UD reference
`UD18` — *"Prototype interface and permitted demonstration material"* (`01_Project_Management/decisions.csv` row `DEC0018`).

## Decision & Evidence (`2026-11-21`)
1. **Minimal Stable Interface (`Single Inference Path`):**
   - Core reusable Python engine: `src/opg/inference_prototype.py` (`OPGPrototypeEngine`), reusing frozen `src/opg/preprocessing.py` (`prepare_image_and_boxes`, `inverse_transform_box`) and `ONNXRuntime` (`CPUExecutionProvider`, `FP32`, `BS=1`).
   - Thin CLI entry point: `13_Automation/run_opg_inference.py` supporting `--model-id`, `--input`, `--out-json`, and optional `--out-overlay`.
   - Any future hosted web showcase (`STEP-047–049`, `FastAPI`/web layer) **MUST** call `OPGPrototypeEngine` directly so zero preprocessing or threshold drift can occur between evaluated metrics and live demonstrations.
2. **Supported Evaluated Models (`CC-BY-NC-SA-4.0` Isolated):**
   - Supports the `7` static `ONNX` (`opset=17`) exported models verified in `STEP-032`/`STEP-034` (`0.983–0.997` PyTorch box parity IoU): primary showcase defaults **`MODEL0008`** (`TrackE UAE@640`, `mAP@0.50 = 0.8246`, `201.6 ms` CPU), **`MODEL0005`** (`TrackA Romania 13-class@1280`, `mAP@0.50 = 0.4165` / external `0.4338`, `878.1 ms` CPU), and **`MODEL0013`** (`TrackD Hanoi PAI 3–5@1280`, `mAP@0.50 = 0.4868`, `847.9 ms` CPU), plus comparator exports (`MODEL0001`, `MODEL0002`, `MODEL0003`, `MODEL0010`).
   - **`MODEL0004` (`TrackB` DENTEX, `CC-BY-NC-SA-4.0`)** remains excluded from prototype exports to maintain strict license isolation.
3. **Permitted Demonstration Material & Guardrails:**
   - Curated local/offline demonstration inputs are strictly restricted to de-identified `CC-BY-4.0` radiographs (`DS0001`, `DS0004`, `DS0005`) retained **off-Git** (`08_Checkpoints/artifacts/` / `03_Datasets/raw/`) with source attribution; automated tests use synthetic blank/corrupt inputs + local off-Git verification when available.
   - Every structured JSON output and rendered visual overlay embeds an explicit **non-clinical research-only disclaimer** and cleanly distinguishes `OK`, `ZERO_DETECTIONS` (never `"no disease"`), and `ERROR`.
