## Decision & Evidence (`2026-11-21`)

1. **Three-Tier Sensitivity & Licensing Architecture (`ARCH0001`):**
   - **Tier 1 — Public Git Release (`Public-Git-Release`):**
     - *Scope:* Python package (`src/opg/`), automation scripts (`13_Automation/`), unit test suite (`tests/`), governance/split/annotation/evaluation CSV & JSON manifests (`SPLIT0001–0006`, `FREEZE0001`, `EVAL0001–0014`, `XSHIFT01–06`, `TIMING`, `ERRREV0001`, `REPRO0001`), vector SVG figures & MD/LaTeX tables (`FIG0001–0006`, `TAB0001–0006`), thesis manuscript & defense deck (`WRIT0001–0008`, `WRIT0014`), and concise paper package (`WRIT0009–0013`).
     - *License & Host:* Original code under `MIT` (compatible with Ultralytics `AGPL-3.0` via external CLI/API invocation); original documentation, figures, and tables under `CC-BY-4.0`. Hosted publicly on GitHub (`https://github.com/akhtaruzzamananik/Thesis-for-Defense`, immutable tag `v1.0.0-arch0001`), with `tracked_forbidden_count = 0`.
   - **Tier 2 — Restricted Off-Git Academic Artifact Storage (`Restricted-OffGit-Academic`):**
     - *Scope:* Frozen PyTorch checkpoints (`MODEL0001–0003`, `MODEL0005–0013` `.pt`), `7` static `.onnx` exports (`MODEL0005`, `MODEL0001–0003`, `MODEL0013`, `MODEL0010`, `MODEL0008`), `STEP-032` raw `predictions.jsonl` logs, off-Git `2×2` visual error review sheets (`EVAL####_review_sheet.jpg`), and future institutional submission receipt files. Raw public radiographs (`DS0001`, `DS0003–DS0006`) are retrieved directly from their authoritative Zenodo/Mendeley/GitHub DOIs (`03_Datasets/datasets.csv`) and verified via `SPLIT0001–0006` SHA-256 manifests rather than re-hosted publicly.
     - *Storage & Access:* Maintained in dual-copy off-Git storage (`08_Checkpoints/artifacts/` on primary workstation + encrypted Private Team Drive mirror) verifiable bit-for-bit against the SHA-256 digests in `15_Archive/archive_manifest.csv`.
   - **Tier 3 — License-Isolated Non-Commercial Artifacts (`Restricted-NC-SA-Isolated`):**
     - *Scope:* `DS0002` (DENTEX, `CC-BY-NC-SA-4.0`) radiographs and trained checkpoint `MODEL0004` (`08_Checkpoints/artifacts/EXP0003/weights/best.pt`).
     - *Constraint:* Excluded from ONNX prototype export (`DEC0018`), excluded from any commercial or unrestricted weight bundle, and marked `CC-BY-NC-SA-4.0 (Non-Commercial Share-Alike Only)` in `15_Archive/archive_manifest.csv`.

2. **Retention Period & Post-Project Custodianship:**
   - **Retention Window:** Minimum **`5` years** from the DIU CSE thesis defense date (`2026–2031`).
   - **Post-Project Owners & Access Contacts:** Co-owned jointly by **Akhtaruzzaman Anik (`232-15-252`, Primary Archive Custodian)** and **Mahajub Al Shabah (`232-15-900`, Co-Custodian)**, with academic oversight by **Ms Faiza Feroz** (Supervisor, Dept. of CSE, Daffodil International University).
   - **Immutability Rule:** Earlier `ARCH####` snapshots and submitted file bundles are never overwritten; any future post-defense addendum (e.g., recording the final DIU portal receipt in `STEP-043` or adding a live web deployment `DEPLOY0001` from `STEP-049`) creates an additive `ARCH0002` delta manifest while preserving `ARCH0001` intact.
