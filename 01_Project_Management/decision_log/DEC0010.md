## question

Which exact YOLO implementation, architecture scale(s), pretrained weight origin, and license compliance policy are approved as the primary baseline and comparators for `REL0001–REL0006`?

## report facts and locators

- Deleted report facts preserved in `OS §1.3` and `§5.1`: The report specifies YOLO-based object detection on `2D OPG` images without naming a YOLO version, package, scale, or weight policy (`UD10`).

## planning options and evidence (`STEP-022` Candidate Matrix)

Five documented open-source YOLO implementations were evaluated in `06_Models/candidates.csv`:
1. **Option 1 (`MC0004 WongKinYiu/yolov9`, `GPL-3.0`):** Rejected as primary baseline due to separate trainer codebase confounder and higher auxiliary-branch VRAM footprint at `1280×1280`.
2. **Option 2 (`MC0005 THU-MIG/yolov10`, `AGPL-3.0`):** Rejected as primary baseline because its NMS-free head alters the `UD13` `NMS IoU` evaluation protocol and showed mixed OPG recall (`P0030`).
3. **Option 3 (Adopted — Unified `ultralytics` `8.3.x` Stack: `MC0001 YOLO11s` Primary Baseline + `MC0002 YOLOv8s` Cross-Gen Comparator + `MC0003 YOLO11m` Conditional Scale Comparator):**
   - **Primary Baseline (`MC0001`):** `ultralytics` `YOLO11s` (`yolo11s.pt`, COCO-80 pretrained, `~9.4M` params, `AGPL-3.0`) — fits Kaggle `16 GB` GPU (`T4`/`P100`) at both `640×640` (`PP0001–0003`) and `1280×1280` (`PP0004`), natively reads `REL0001–REL0006` without altering `G08`, and avoids assuming newer = better by testing head-to-head against `YOLOv8s`.
   - **Cross-Gen Comparator (`MC0002`):** `ultralytics` `YOLOv8s` (`yolov8s.pt`) inside the identical codebase/dataloader (`0` implementation confounders).
   - **Conditional Scale Comparator (`MC0003`):** `ultralytics` `YOLO11m` (`yolo11m.pt`) for `Track A` (`UMFIH`) comparison with `P0015` if Kaggle GPU budget permits.
   - **License & Weight Policy:** Official Ultralytics GitHub release weights (`SHA-256` recorded at `STEP-023/026`, stored off-Git in `06_Models/weights/`); `AGPL-3.0` compliance maintained by keeping thesis & `S16` web demo code open-source; `DS0002 DENTEX` (`CC-BY-NC-SA-4.0`) models kept non-commercial and isolated.

## recommendation and rejected alternatives

Adopt **Option 3** (`MC0001 YOLO11s` primary baseline, `MC0002 YOLOv8s` comparator, `MC0003 YOLO11m` conditional comparator).
