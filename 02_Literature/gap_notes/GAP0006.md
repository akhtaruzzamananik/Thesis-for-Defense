## ReportGap

`G6: condition-specific detection and efficiency` (`OS §3.3`)

## proposed statement

Existing dental `OPG` object detectors fail to demonstrate multi-object real-time inference efficiency alongside reliable multi-pathology detection performance across heterogeneous conditions.

## search coverage

Tested across `180` harvested files (`58` duplicates) -> `122` unique screened records (`42` Core full-text: `23` Group A direct OPG object detectors + `19` Group B contextual studies; `55` Reserve [`27` YOLO], `25` Excluded). Specifically audited every Core paper's hardware disclosure, timing boundary (`T_pre + T_infer + T_post` vs pure forward pass vs absent), `FPS`/`ms/OPG`, parameter count / `GFLOPs`, and concurrent multi-class pathology accuracy.

## supporting and contradicting P IDs

- **Contradicting `PaperIDs` (prove single-stage GPU forward passes CAN exceed `30 FPS`):**
  - `P0006` (`Khurshid et al., 2026`, `Tesla P100 16GB`, `1024×1024`): `YOLOv11-n` `6.90 ms` (`~144.9 FPS`), `YOLOv11-OBB-s` **`14.2 ms` (`~70.4 FPS`)**, `YOLOv11-s` `14.4 ms` (`~69.4 FPS`) vs `RT-DETR-l` `44.6 ms` (`22.4 FPS`) and `RT-DETR-xl` `80.1 ms` (`12.5 FPS`) *(pre/post boundary unreported; `mAP` inflated by pre-split augmentation)*.
  - `P0009` (`Peng et al., 2026`, `RTX 5060 Laptop 8GB`, `640×640`): Pure GPU **`FPS_infer`** of `YOLOv8n = 478.78`, `YOLO26n = 422.98`, `YOLOv11n = 405.16`, `YOLOv6n = 273.22`, `YOLOv5n = 267.18`, `RCTE-Net = 202.34 FPS` *(explicitly omits `T_pre`, `T_post`, and defined `FPS_all` from Results; `Periapical mAP50 = 0.0726`, `Caries = 0.2497`)*.
  - `P0015` (`Eftimie et al., 2025`, `RTX 3060` + `i7-12700H`, `1024×1024`): **`YOLO11m` reached `33.23 ms` (`30.1 FPS`) GPU and `39.93 ms` (`25.0 FPS`) CPU**, `YOLO11n` `10.00 ms` (`100.0 FPS`) GPU / `19.43 ms` (`51.5 FPS`) CPU, outperforming `RT-DETR-l` (`67.11 ms` = `14.9 FPS` GPU) and `YOLOv8x` (`120.34 ms` = `8.3 FPS` GPU) *(however, `YOLO11m` dropped externally to `mAP@0.5 = 0.5366` and per-class external APs were weak in `P0023`)*.
  - `P0012` (`Wang & Li, 2026`, `4 × NVIDIA V100`, `512×512`): Legacy `YOLOv5` reached `45.7 FPS` (`~21.9 ms`) vs `Proposed ViT+FPN` at `14.2 FPS` (`~70 ms`).
  - `P0020` (`Ragab et al., 2025`, `RTX A5000`, `640×640`, `BS=32`): `YOLOv7-M` `11.1 ms` (`~90.1 FPS`, vs `YOLOv7 12.9 ms`), though timing boundaries are missing and `Tables 6–7` contain mathematical `F1 > max(P, R)` errors.
- **Supporting `PaperIDs` (prove runtime reporting gaps, unverified `"real-time"` claims, end-to-end bottlenecks, and the accuracy–speed trade-off):**
  - **Complete omission of per-OPG inference speed (`31/42 = 73.8%` of ALL Core studies omit `FPS`/`ms/OPG`):**
    - **`14 / 23` (`60.9%`) Group A direct OPG detectors report ZERO per-image inference latency (`ms`/`FPS`):** `P0003, P0004, P0005` (`19.7 GFLOPs` only), `P0007, P0014` (Flask web app with zero timing), `P0016` (only `0.90 s/epoch`), `P0017` (qualitative `"Faster"` claims only), `P0018` (`0 FPS` despite `"real-time detection"` claims for `YOLOv8+RT-DETR+WBF`), `P0019` (`0 FPS` despite `YOLOv10` latency claims), `P0021, P0022, P0023, P0024, P0025`.
    - **`17 / 19` (`89.5%`) Group B studies report ZERO OPG inference latency:** `P0002` (GPU contradiction `A100` vs `T4`, qualitative only), `P0010, P0026–P0028` (`P0028` cites `<1 s ResNet` & `15 min` manual charting), `P0030–P0040` (including `"real-time"` claimants `P0033` and `P0035`), `P0042` (`P0041` reports `90 ms/OPG` [`~11.1 FPS`] on `RTX 2080 Ti`; `P0029` reports `426.0 ms` [`2.35 FPS`] raw vs `3,366.7 ms` [`0.30 FPS`] CPU enhancement cascade).
  - **Measured multi-tile, cascaded, and web-deployed pipelines fall well below real-time (`0.07–6.3 OPG/s`):**
    - `P0008` (`Oztekin et al., 2026`, `RTX 4090`): Achieving strong small-lesion `PAI 3–5` sensitivity via dense `26.7`-tile sliding window + NMS dropped throughput to **`0.42 s/OPG` (`~2.38 OPG/s`)**.
    - `P0011` (`Scarano et al., 2026`, `RTX 5000 Ada`): Cascaded Tooth-Seg -> Lesion-Det took **`0.5541 s/OPG` (`~1.80 FPS`)** at `1280px` and **`0.1589 s/OPG` (`~6.29 FPS`)** even after vertical ROI `640px` optimization (`0.5497 s/OPG` CPU).
    - `P0001` (`Baseri Saadi et al., 2026`): Full Streamlit Cloud Run pipeline from upload through Word report took **`15 ± 1.4 s/OPG`** (standalone GPU `FPS` omitted).
    - `P0013` (`Özden et al., 2026`): Reports only a coarse work-PC bound (`<500 ms` [`>2 FPS`] inference, `<1 s` report), omitting exact `RTX A6000` GPU timings.
  - **Timing-boundary & multi-pathology trade-off:** `P0009` explicitly defines `FPS_all` (`T_pre + T_infer + T_post`) yet omits `T_pre`, `T_post`, and `FPS_all` from Results while losing radiolucent sensitivity (`Periapical mAP50 = 0.0726`); `P0012` shows Transformers trail CNNs on speed (`14.2` vs `45.7 FPS` on `4×V100`); `P0029` proves CPU preprocessing (`CLAHE+FFT+Canny`) causes a `7.9×` slowdown (`426 -> 3,367 ms`) with zero accuracy gain.

## independence

Verified independently across virtually every contributing research group: `28+` separate institutions in Europe, East/South/West Asia, and Latin America fail to standardize inference boundary timing (`P0001–P0042`), while `P0006, P0008, P0009, P0011, P0012, P0015, P0020, P0029, P0041` span independent hardware rigs (`Tesla T4/P100`, `RTX 2080Ti/3060/4090/A5000/5000 Ada/5060`, `4×V100`).

## feasibility

Very high (`O3` & `O2`). Directly feasible for a 2-student Phase 2 thesis on standard hardware (e.g., Kaggle/Colab GPU + local CPU benchmark):
- Measure and report **both GPU and CPU single-image latency (`batch = 1` after warmup)** with **explicit timing boundaries (`T_preprocess + T_infer + T_postprocess/NMS = T_e2e` and `FPS_e2e`)**, alongside parameter count (`M`), `GFLOPs`, and peak VRAM.
- Jointly optimize **multi-class detection accuracy (`mAP@0.50`, `mAP@0.50:0.95`, per-class pathology AP)** and **bounded runtime efficiency**, avoiding heavy unmeasured cascades (`P0011`, `P0018`, `P0029`) while proving any inference latency claim empirically inside `S14` / `S16` rather than echoing unmeasured `"real-time"` clichés.

## narrower interpretation

1. **Blanket speed failure refuted:** Single-stage compact YOLO architectures (`YOLO11n/m`, `YOLOv8n`, `YOLOv11s`) already exceed `30 FPS` on raw GPU forward passes (`P0006, P0009, P0012, P0015, P0020`).
2. **Verified surviving `G6` gap:** **`73.8%` (`31/42`) of Core OPG studies omit per-image inference latency** (frequently making unsupported `"real-time"` claims, e.g., `P0005, P0017–P0019, P0033, P0035`), **zero Core papers benchmark both leak-free multi-class pathology accuracy (`mAP@0.5:0.95`) AND reproducible end-to-end (`T_pre + T_infer + T_post`, CPU + GPU) timing**, and methods that preserve high small-lesion recall (`P0008` dense tiling `2.38 OPG/s`, `P0011` ROI cascade `6.29 FPS`, `P0029` enhancement `0.30 FPS`) currently sacrifice single-pass throughput.
