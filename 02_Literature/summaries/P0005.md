## Verified citation

Khurshid, Z., Alsleem, M. H., Aljubairah, F. A., Alghafli, H. A., Alasafirah, A. O., Alibrahim, B. A., Alshamrani, A. A., & Alsuhaymi, A. N. (2026). Dual Framework for Classification and Detection of Third Molar Impaction in Panoramic Radiographs. *International Dental Journal*, 76, 109430. https://doi.org/10.1016/j.identj.2026.109430 (PDF p. 1).

## question/task/modality

- **Modality:** 2D Orthopantomogram (`OPG`) radiographs (multinational public dataset from Mendeley Data, pp. 2–4).
- **Task:** Dual independent frameworks for **6-class mandibular third molar impaction subtype analysis** (`Distoangular`, `Mesioangular`, `Vertical`, `Horizontal`, `Buccolingual`, `Inverted`):
  1. *Framework 1 (End-to-end Object Detection):* Bounding-box localization and 6-class subtype classification using modified `YOLOv11n` (with Multihead Self-Attention `MHSA`) and GA-optimized `YOLOv10` (pp. 1–4).
  2. *Framework 2 (Feature-based Classification):* Deep feature extraction via `ResNet50` and `InceptionNetV3` followed by `10` classical ML classifiers (`Fine KNN`, `Neural Network`, `SVM`, `AdaBoost`, `Random Forest`, etc., pp. 2–6).

## data/counts

- **Dataset size & provenance (`pp. 2, 4, 5, 10, Table 1`):** **`5,796` panoramic radiographs** sourced from multinational Mendeley Data repositories `[22, 23]` and released with annotations/code at **Mendeley Data `doi:10.17632/ckt876jzr6.1`** (`CC BY 4.0`, Ethics Ref `KFU-REC-2025-SEP-ETHICS3540`, pp. 3, 10–11).
- **Class instance distribution (`Table 1`, p. 5 — `Instances = Training + Validation + Testing`):**
  - `0: Distoangular`: `1,470` (`470` train / `500` val / `500` test -> augmented train `2,000`)
  - `1: Mesioangular`: `1,100` (`100` train / `500` val / `500` test -> augmented train `2,000`)
  - `2: Vertical`: `939` (`339` train / `300` val / `300` test -> augmented train `2,000`)
  - `3: Horizontal`: `817` (`217` train / `300` val / `300` test -> augmented train `2,000`)
  - `4: Buccolingual`: `734` (`334` train / `200` val / `200` test -> augmented train `2,000`)
  - `5: Inverted`: `736` (`336` train / `200` val / `200` test -> augmented train `2,000`)
  - *Total original:* `5,796` (`1,796` train / `2,000` val / `2,000` test); *Augmented training set:* `12,000` (`2,000 × 6` classes).

## annotation

- **Tool & workflow (`pp. 2–4`):** Annotated in `CVAT` with bounding boxes and 6 impaction labels by final-year undergraduate dental students and dental interns, verified/independently labeled by two dental specialists (`Z.K.`, `A.A.F.`).
- **Inter-rater agreement (`p. 1, 4`):** **Cohen's kappa `κ = 0.92 (p < 0.001)`**.

## split

- **Hold-out allocation (`p. 4, Table 1`):** Fixed hold-out split performed **prior to augmentation** into `1,796` training (`31.0%`), `2,000` validation (`34.5%`), and `2,000` independent testing (`34.5%`) images/instances. Patient-level grouping is `not reported` (dataset anonymized without patient demographics, p. 3).

## model

- **Object detectors (`pp. 1, 4, 7, Table 4`):**
  - `Modified YOLOv11n`: Integrates Multihead Self-Attention (`MHSA`) modules into the neck before the detection head; **`8.9M` parameters, `19.7 GFLOPs`**.
  - `Modified YOLOv10`: Attention-enhanced and genetically optimized (`GA`) variant; **`11.1M` parameters, `28.4 GFLOPs`**.
- **Feature classifiers (`pp. 4–6, Table 3`):** `ResNet50` and `InceptionNetV3` feature extractors paired with `Fine KNN (k = 1, Euclidean distance)`, Neural Network, Cubic/Linear SVM, Logistic Regression, Decision Tree, Naive Bayes, Gradient Boosting, Random Forest, and AdaBoost.

## preprocessing

- **Operations (`p. 4`):** Standardized dimensions, orientation, brightness, contrast, and normalization.
- **Augmentation & GAN balancing (`p. 4, Table 1`):** Geometric and photometric augmentations plus **`StyleGAN2-ADA`** synthetic radiograph generation applied to the training split to balance all 6 classes to `2,000` training samples each (`12,000` total).

## training

- **Compute platforms (`p. 4`):** YOLO models trained on Google Colab (**NVIDIA A100 GPU**); ResNet50/InceptionNetV3 feature pipelines executed on Kaggle (**NVIDIA P100 GPU**). Exact epochs, batch size, learning rate, and optimizer for YOLO training are `not reported`.

## metrics/IoU

- **Detection (`Table 4`, p. 7):** Precision (`P`), Recall (`R`), `mAP@0.5`, `mAP@0.5:0.95`, Parameters (`M`), and `GFLOPs`.
- **Classification (`Table 2–3`, pp. 6):** Accuracy, Precision, Recall, F1-score, ROC-AUC, train time (`s`), and prediction time (`s`).

## timing/hardware

- **Hardware (`p. 4`):** NVIDIA A100 (Colab, detection) and NVIDIA P100 (Kaggle, classification).
- **Speed metrics (`Table 3 & Table 4, pp. 6–7`):** Classification prediction time is `0.002–0.003 s` for Fine KNN (`0.017–0.020 s` for Neural Network). For `YOLOv10` and `YOLOv11n`, computational complexity (`28.4` vs `19.7 GFLOPs` and `11.1M` vs `8.9M` params) is reported, but actual inference latency (`ms/image`) or **`FPS` is `not reported`**.

## results with locators

- **Object Detection Performance (`Table 4`, p. 7):**
  - *`Modified YOLOv11n` (Overall):* Precision `78.20%`, Recall `94.40%`, **`mAP@0.5 = 88.90%`**, **`mAP@0.5:0.95 = 85.70%`** (`8.9M` params, `19.7 GFLOPs`).
  - *`Modified YOLOv10` (Overall):* Precision `76.20%`, Recall `93.10%`, **`mAP@0.5 = 87.60%`**, **`mAP@0.5:0.95 = 84.20%`** (`11.1M` params, `28.4 GFLOPs`).
  - *Class-wise `YOLOv11n` (`P / R / mAP@0.5 / mAP@0.5:0.95`, Table 4, p. 7):*
    - `Distoangular`: `68.80% / 93.20% / 86.10% / 81.60%`
    - `Mesioangular`: `64.50% / 87.40% / 82.10% / 76.80%`
    - `Vertical`: `75.20% / 93.60% / 84.90% / 81.10%`
    - `Horizontal`: `70.70% / 89.20% / 82.10% / 76.20%`
    - `Buccolingual`: `87.50% / 99.90% / 97.40% / 97.10%`
    - `Inverted`: `100.0% / 100.0% / 99.60% / 99.60%`
- **Detection Ablation (`p. 8`):** Baseline `YOLOv10` (`82.1% mAP@0.5`) -> `+MHSA` (`85.6%`, `+3.5%`) -> `+StyleGAN2-ADA` (`88.5%`, `+2.9%`; total `+6.4%` gain; note slight text discrepancy between `88.5%` on p. 8 and `87.60%`/`88.90%` in Table 4).
- **Classification Performance (`Table 3`, p. 6):** `ResNet50 + Fine KNN` achieved `97.56%` Accuracy, `96.07%` Precision, `96.21%` Recall, `96.10%` F1-score (`InceptionNetV3 + Fine KNN`: `97.33%` Accuracy, `95.30%` F1).

## limitations

- **Author-stated (`pp. 8–9, Table 5`):** (1) Moderate detection precision (`62.4%–75.2%`) for `Mesioangular`, `Distoangular`, and `Horizontal` subtypes due to 2D OPG projective overlap; (2) relies on 2D imaging without 3D CBCT verification of IAN proximity; (3) requires broader multicenter validation; (4) classification and detection frameworks are separate rather than fused.

## critique

- Valuable `YOLOv10` vs `YOLOv11n` benchmark with explicit `κ = 0.92` specialist-verified CVAT annotations and open Mendeley Data link (`doi:10.17632/ckt876jzr6.1` — a strong candidate to inspect at `STEP-010` for `UD02`!).
- Methodological caution: (1) Table 1 uses an unusual `~31% / 34.5% / 34.5%` (`1,796 / 2,000 / 2,000`) split where Mesioangular has only `100` training samples vs `500` val and `500` test samples; (2) near-perfect `99.6%–100%` test scores on `Inverted` and `Buccolingual` require auditing the Mendeley repository at `STEP-010` to verify no pre-augmented duplicates existed in the parent dataset; (3) claims "real-time detection" in the abstract/conclusion based solely on `GFLOPs (19.7)` without reporting measured `FPS` or latency (`ms`) — directly supporting our **Gap `G6`**!

## reuse

- Direct comparator for `Group A` (`YOLOv10` vs `YOLOv11n`, `mAP@0.5` and `mAP@0.5:0.95`), `G6` (claims real-time efficiency via GFLOPs without reporting measured FPS boundary), and candidate public dataset source (`doi:10.17632/ckt876jzr6.1`) for `STEP-010`.

## conflicts

- None; highlights why our project (`RF12`, `UD14`) must measure actual inference `FPS`/latency rather than only reporting parameter count or GFLOPs.

## unresolved fields
