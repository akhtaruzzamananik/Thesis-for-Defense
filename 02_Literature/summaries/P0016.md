## Verified citation

Şevik, U., & Mutlu, O. (2025). Detection of Dental Anomalies in Digital Panoramic Images Using YOLO: A Next Generation Approach Based on Single Stage Detection Models. *Diagnostics*, 15(15), 1961. https://doi.org/10.3390/diagnostics15151961 (PDF p. 1).

## question/task/modality

- **Modality:** 2D pediatric digital panoramic radiographs (`OPGs`) in the mixed dentition period (`pp. 1–4`).
- **Task:** Simultaneous 4-class bounding-box object detection of pediatric dental findings (`Dental Caries`, `Deciduous Tooth`, `Root Canal Treatment`, and `Pulpotomy`), benchmarking **`YOLOv8x`, `YOLOv9e`, `YOLOv10x`, and `YOLOv11x`** on an internal validation cohort and evaluating the selected **`YOLOv11x`** model on an independent external test set (`pp. 1, 3–8, 10–15`).
- **Critical Class Ontology Definition (`pp. 4–5`):**
  1. `Dental Caries` (`830` instances, `43.57%`): Explicitly defined on `p. 4` to **combine both active radiolucent carious lesions AND completed radiopaque dental restorations/fillings** into a single unified class because the primary public dataset (`Zhang et al. [20]`) did not consistently separate them.
  2. `Deciduous Tooth` (`791` instances, `41.52%`): Primary teeth.
  3. `Root Canal Treatment` (`171` instances, `8.98%`): Teeth with radiopaque intracanal filling material (pragmatically including apexification, `p. 4`).
  4. `Pulpotomy` (`113` instances, `5.93%`): Primary teeth with a distinct radiopaque base material inside the coronal pulp chamber (`pp. 4–5`).

## data/counts

- **Tier 1 — Primary Internal Dataset (`pp. 1, 3, 7, 18, Table 1`):** **`644` pediatric OPGs** sourced from the public **`Children's Dental Panoramic Radiographs Dataset` (`Zhang et al., Scientific Data 2023, 10:380`, Ref `[20]`, URL: `https://www.kisa.link/PAhjU`)**, containing **`1,905` total bounding-box annotations** across the 4 classes (`Dental Caries = 830 [43.57%]`, `Deciduous Tooth = 791 [41.52%]`, `Root Canal Treatment = 171 [8.98%]`, `Pulpotomy = 113 [5.93%]`, `Table 1`, p. 3).
- **Tier 2 — Independent External Test Dataset (`pp. 1, 3, 7, 18`):** **`150` pediatric OPGs** curated from three public Roboflow Universe repositories (`https://www.kisa.link/wMjfV`, `https://www.kisa.link/TsHld`, `https://www.kisa.link/RkaVO`, `p. 18`). Per-class instance counts in the `150` external test images are `not reported`.

## annotation

- **Tool & Dual-Expert Verification (`pp. 4–5`):** Labeled with bounding boxes in `Label Studio` and independently verified by two specialists across all `644 + 150 = 794` radiographs: an oral & maxillofacial radiologist (`>10` years experience) and a board-certified pediatric dentist (with a radiology professor designated as tie-breaker).
- **Inter-rater reliability (`p. 5`):** Authors report **Cohen's kappa `κ = 1.00`** (`"no disagreements arose between the two primary experts"` across all labels and coordinates).

## split

- **Tier 1 Internal Split (`p. 7`):** Multi-label iterative stratification (`80% / 20%`) of the `644` primary OPGs into **`515` training** and **`129` internal validation** images.
- **Tier 2 External Hold-out (`p. 7`):** **`150` independent external test** images (strictly held out and evaluated once on the selected `YOLOv11x` checkpoint). Patient-level metadata is `not reported` (anonymized public datasets).

## model

- **4 Benchmarked YOLO Architectures (`Table 2`, p. 6 — at `640 × 640` input):**
  1. `YOLOv8x`: `68.16M` parameters, `311.2 GFLOPs`
  2. `YOLOv9e` (`PGI + GELAN`): `58.1M` parameters, `192.5 GFLOPs`
  3. `YOLOv10x` (NMS-free dual label assignment): `29.5M` parameters, `160.4 GFLOPs`
  4. `YOLOv11x` (transformer-based attention neck): `56.9M` parameters, `194.9 GFLOPs`.

## preprocessing

- **Operations (`p. 4`):** Resized to `640 × 640` pixels and pixel intensities normalized to `[0, 1]`. No `CLAHE`, contrast enhancement, or filtering applied.
- **Training Augmentation (`p. 8, Table 3`):** `Mosaic`, `MixUp`, and random affine transformations (rotations, scaling, translations).

## training

- **Hyperparameters (`pp. 8, 10, Table 3`):** Trained **from scratch** (`p. 8, line 393`) for `500` epochs, batch size `16`, `SGD` optimizer, initial learning rate `lr0 = 0.01` with cosine annealing, momentum `0.937`, weight decay `0.0005`, training `IoU threshold = 0.5`, composite `CIoU + BCE + DFL` loss, implemented in Python `3.11`, PyTorch `2.5.1`, Ultralytics `v8.3.158`, CUDA `12.1`, cuDNN `8.9.2`.

## metrics/IoU

- **Reported metrics (`pp. 8–10, Tables 4–9`):** Accuracy, Recall, Precision, F1-Score (note: Formula 4 on `p. 9` has a typographical label `Recall = 2 * Precision * Recall / (Precision + Recall)` for F1-Score), `mAP50` (`IoU = 0.50`), `mAP50-95` (`IoU = 0.50:0.95`), validation loss components (`Box`, `CLS`, `DFL`), and training/validation time per epoch (`s`).

## timing/hardware

- **Hardware (`p. 10`):** Workstation with **Intel Core i9-14900K CPU**, `64 GB DDR5 RAM`, and **NVIDIA GeForce RTX 4090 GPU (`24 GB GDDR6X`)**.
- **Training & Validation Speed per Epoch (`Table 7`, p. 14 — across `515` train / `129` val images):**
  - `YOLOv8x`: Train `0.92 s/epoch`, Val `0.89 s/epoch`
  - `YOLOv9e`: Train `0.91 s/epoch`, Val `0.89 s/epoch`
  - `YOLOv10x`: Train `0.92 s/epoch`, Val `0.89 s/epoch`
  - `YOLOv11x`: Train **`0.90 s/epoch`**, Val **`0.90 s/epoch`**.
- **Per-image inference latency (`ms/image`) or `FPS`:** **`not reported`**.

## limitations

- **Author-stated (`p. 17`):** (1) Moderate sample size (`644` primary + `150` external OPGs); (2) severe class imbalance (`Dental Caries = 43.57%` vs `Pulpotomy = 5.93%`); (3) detects presence only without severity grading; (4) compares only single-stage YOLO models without two-stage or segmentation comparators.

## critique

- **Three critical full-text audit findings (`OS §3.2`):**
  1. **Conflated `'Dental Caries'` class definition (`p. 4`, `UD04`):** Because `Zhang et al. [20]` did not separate active radiolucent caries from radiopaque fillings, the authors merged **both active caries AND dental restorations** into a single `'Dental Caries'` class! High-contrast radiopaque metal/composite fillings are much easier to detect on 2D OPG than subtle radiolucent caries (`P0003`, `P0009`), which explains why `'Dental Caries'` recall reaches `79%–89%` here — a vital caveat when comparing `P0016` against true radiolucent caries studies!
  2. **`mAP50` vs `mAP50-95` reversal (`Table 5`, p. 11):** While `YOLOv11x` achieved the highest `mAP50` (`0.91` vs `0.89–0.90`), **`YOLOv8x` and `YOLOv10x` achieved higher strict `mAP50-95` (`0.71` vs `0.69` for `YOLOv11x`)**, showing tighter bounding-box localization in `v8x`/`v10x` despite `v11x`'s higher `IoU=0.50` recall.
  3. **Unrealistically perfect `κ = 1.00` (`p. 5`) & missing `FPS` (`G6`):** Claiming zero disagreements (`κ = 1.00`) between two independent clinicians across `1,905+` bounding boxes on `794` pediatric OPGs is statistically implausible unless the second reviewer inspected non-blinded boxes; and despite motivating the paper via clinical inference speed (`pp. 2–3`), no per-image inference latency (`ms`) or `FPS` is reported.
