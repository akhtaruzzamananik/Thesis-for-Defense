## Verified citation

Bhoopalan, R., Mirdula, S., Kannusamy, P., Gayathri, D., Manikandan, D., & Ramaswamy, K. (2026). A self attention based deep learning framework for accurate and efficient dental disease detection in OPG radiographs. *Scientific Reports*, 16, 5914. https://doi.org/10.1038/s41598-026-36672-2 (PDF p. 1).

## question/task/modality

- **Stated vs actual task (`pp. 1, 4–5, 8–12`):** Although the title says *"dental disease detection in OPG radiographs"* and p. 9 mentions optional Mask R-CNN/NMS post-processing conceptually, the actual implemented and evaluated task is **4-class mutually exclusive image-level classification** (`Hypodontia`, `Gingivitis`, `Caries`, `Calculus`) using Vision Transformer (`ViT`) and `Swin Transformer` following U-Net dental-arch ROI cropping (Eqs. 11–16, Table 4, pp. 8, 12).
- **Modality ambiguity (`p. 4`):** Title, Fig. 1, and text describe `Orthopantomogram (OPG)` radiographs, but Section *"OPG image set"* (p. 4) explicitly states the data was taken from *"the Oral Dataset set from Kaggle by Sajid 2024 [29]... These high resolution RGB intraoral images are labelled under various dental conditions."*

## data/counts

- **Reported counts (`pp. 4–5, Table 1`):** Source Kaggle repository said to contain `~13,000` images across 6 classes, from which `4` classes totaling **`5,098` samples** were used (`Table 1`, p. 5):
  - `Hypodontia`: `1,251` (`876` train / `188` val / `187` test)
  - `Gingivitis`: `2,332` (`1,632` train / `350` val / `350` test)
  - `Caries`: `219` (`153` train / `33` val / `33` test)
  - `Calculus`: `1,296` (`907` train / `194` val / `195` test)
- **Patient count:** `not reported`.

## annotation

- Pre-labeled public Kaggle dataset (`Sajid 2024 [29]`, p. 4). Page 5 states U-Net dental arch segmentation showed "high agreement to expert annotations", but annotator credentials, tool, bounding-box/mask protocol, and inter-observer agreement (`kappa`/`Dice`) are `not reported`.

## split

- **Proportions (`p. 5, Table 1`):** `70%` training (`3,568`), `15%` validation (`765`), `15%` testing (`765`), repeated across `5` random seeds in the ablation study (p. 14).
- **Critical data-leakage risk (`p. 5`):** Section *"Image annotation"* (p. 5) states: *"The images of Gingivitis and Hypodontia are flipped, rotated and then the brightness are adjusted so as to reduce the overfitting. The dataset is then splitted in a regular procedure of 70% training with 15% validation and 15% testing"* — indicating augmentation prior to splitting, with no patient-level grouping reported.

## model

- **Architectures (`pp. 5, 8, 11`):**
  - `Vision Transformer (ViT-Base)`: Patch size `16 × 16`, embedding dim `D = 768`, `L = 12` encoder layers, `12` attention heads, `~86M` parameters (`336 MB` memory), ImageNet pretrained checkpoints (pp. 5, 11).
  - `Swin Transformer`: Patch size `4 × 4`, window size `6 × 6` (`p. 9`), `12` transformer layers, `~88M` parameters (`340 MB` memory), ImageNet pretrained (pp. 8–9, 11).
  - `U-Net`: Encoder-decoder with skip connections used for preprocessing dental arch ROI extraction (p. 5, Fig. 4).

## preprocessing

- **Pipeline (`pp. 5, 9`):** (1) `CLAHE` for contrast normalization, (2) Gaussian smoothing filter (`σ = 1.0`), (3) intensity normalization to `[0, 1]` (or mean/std on p. 9), (4) `U-Net` dental arch ROI cropping, and (5) resizing to `224 × 224 × 3` pixels.

## training

- **Hyperparameters (`p. 11`):** Learning rate `1 × 10^-5`, batch size `64`, `30` epochs, Adam optimizer, cross-entropy loss (Eq. 14, p. 8).

## metrics/IoU

- **Reported metrics (`pp. 9–13, Table 4`):** Classification Accuracy, Precision (PPV), Recall (Sensitivity), Specificity, NPV, FPR, FNR, F1-score (note: Eq. 35 on p. 10 prints an inverted formula `2*(Precision+Recall)/(Precision*Recall)`, though Table 4 values match standard harmonic mean), and AUC-ROC.
- **Object detection metrics (`IoU`, `mAP@0.5`, `mAP@0.5:0.95`):** `not reported` (no bounding-box detection evaluation is performed).

## timing/hardware

- **Hardware discrepancy:** Page 9 states trained on a single **NVIDIA A100 GPU** with mixed precision (`FP16`), whereas Page 11 states implemented on **NVIDIA Tesla T4** in Google Colab.
- **Inference speed (`FPS` / ms per image):** `not reported` (only qualitative statement that Swin has lower latency and `8×8` patches cost `~1.6×` higher inference time than `16×16`, p. 14).

## results with locators

- **Classification performance (`Table 4`, p. 12; `Fig. 11`, p. 14):**
  - *ViT-Base (Overall, `N=5,098`):* Accuracy `96.0%`, Precision `95.8%`, Recall `96.2%`, F1-score `96.0%`, micro-average ROC-AUC `0.968` (p. 13). Class-wise F1: `Hypodontia 96.5%`, `Gingivitis 96.5%`, `Calculus 95.5%`, `Caries 93.5%` (`N=219`).
  - *Swin Transformer (Overall):* Accuracy `95.2%`, Precision `94.0%`, Recall `95.0%`, F1-score `94.5%`, micro-average ROC-AUC `0.958` (p. 13). Class-wise F1: `Hypodontia 95.0%`, `Gingivitis 95.5%`, `Calculus 93.5%`, `Caries 91.5%`.
- **Ablation (`Table 2`, p. 6; `pp. 14–15`):**
  - `U-Net` ROI crop + `CLAHE` vs full image improved ViT overall F1 from `94.7%` to `96.0%` (`+1.3%`, Table 2, p. 6).
  - Removing ImageNet pretraining reduced ViT accuracy by `-5.2%`; increasing patch size to `32` reduced accuracy by `-1.9%` (p. 14).

## limitations

- **Author-stated (`pp. 12, 16`):** Small sample size for `Caries` (`N = 219`) with small/low-contrast lesions; restricted to a single dataset and 4 conditions; lacks external multicenter or prospective clinical validation.

## critique

- **Major methodological warning (`OS §3.2`):** Despite using *"detection in OPG radiographs"* in the title, this study is **strictly 4-class image classification (`Group B`)** and exhibits three serious validity flaws: (1) p. 4 cites a Kaggle *RGB intraoral photograph* dataset (`Sajid 2024`, classes `Gingivitis/Calculus/Caries/Hypodontia`) while claiming OPG analysis, (2) p. 5 describes data augmentation *before* train/val/test splitting (data leakage), and (3) hardware descriptions conflict between p. 9 (`A100`) and p. 11 (`Tesla T4`).
- Consequently, `P0002` is reclassified from `Group A` to **`Group B` (contextual/methodological critique)** in `papers.csv` and must **never** be cited as a verified 2D OPG bounding-box detector.
