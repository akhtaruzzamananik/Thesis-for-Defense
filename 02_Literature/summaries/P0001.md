## Verified citation

Baseri Saadi, S., Gracea, R. S., Ver Berne, J., Claes, P., & Jacobs, R. (2026). Panognostics-Plus: An Integrated Multi-Task AI Framework for Automated Panoramic Radiograph Interpretation with Dental Charting and Structured Reporting—Development and Technical Validation Study. *Journal of Imaging Informatics in Medicine*. https://doi.org/10.1007/s10278-026-02479-w (PDF p. 1).

## question/task/modality

- **Modality:** 2D dental panoramic radiographs (OPGs) acquired on four clinical units: Cranex Tome, Veraviewepocs 2D, VistaPano S, and Planmeca Promax 2D (p. 3).
- **Task:** Multi-task hierarchical pipeline combining: (1) Stage-1 full-OPG bounding-box object detection (`10` target categories), (2) Stage-2 ROI pixel-level instance segmentation (`8` anatomical and restorative categories), (3) periapical lesion detection-and-classification (`radicular cysts` vs `periapical granulomas`), and (4) deterministic FDI tooth mapping, interactive dental charting, and automated Word report generation via a cloud-deployed Streamlit web application (pp. 1–6).

## data/counts

- **Source cohort:** `1,595` retrospective clinical panoramic radiographs from University Hospitals Leuven, Belgium (Ethics approvals `S69363` and `S65708`); mean age `44.2 ± 17.4` years (range `11–89`), `55.2%` female / `44.8%` male (p. 3).
- **Task-specific non-additive image & ROI instance counts (`Table 1`, p. 4):**
  - *Dental anatomy:* Teeth (`304` detection OPGs / `8,922` segmentation ROIs), Maxillary sinus floor (`200` OPGs / `400` ROIs), Normal periodontal bone level (`238` OPGs / `396` ROIs).
  - *Dental treatments:* Dental implants (`260` OPGs / `530` ROIs), Bridges (`167` OPGs / `265` ROIs), Root canal treatments (`329` OPGs / `1,367` ROIs), Crowns (`194` OPGs / `522` ROIs), Dental fillings (`250` OPGs / `1,590` ROIs).
  - *Periapical diagnostics (detection + classification only):* Solitary mandibular radicular cysts (`80` OPGs), periapical granulomas (`72` OPGs) adopted from a prior histopathological/consensus cohort `[20]` (pp. 3–4).
- **Public availability:** Not publicly open; "available from the corresponding author upon reasonable request" (p. 16).

## annotation

- **Tool:** Labelme (`RRID: SCR_025291`) open-source polygon annotation tool (p. 3).
- **Protocol & credentials:** Manual polygons drawn on full OPGs for anatomy/treatments (bounding boxes derived from polygons for Stage-1 detection; cropped polygons used for Stage-2 segmentation). Annotated by experienced dentists and reviewed by a dentomaxillofacial radiologist (`>6` years experience). Periapical lesions labeled with bounding boxes only by two dentomaxillofacial radiologists using histopathology/clinical/radiological consensus, with a third radiologist adjudicating disagreements (p. 3).
- **Inter-annotator agreement metric (e.g., kappa/Dice):** `not reported`.

## split

- **Allocation (`Table 2`, pp. 3–4):** `80%` model development / `20%` independent test set per task (e.g., Teeth: `243` dev / `61` test OPGs; Root canal treatments: `263` dev / `66` test; Implants: `208` dev / `52` test; Crowns: `155` dev / `39` test; Fillings: `200` dev / `50` test; Bridges: `133` dev / `34` test; Radicular cysts: `64` dev / `16` test; Periapical granulomas: `58` dev / `14` test).
- **Leakage control:** Split performed at the **radiograph level** before ROI extraction so all ROIs from the same OPG remained in the same partition; 5-fold cross-validation (`80%` train / `20%` val per fold) executed strictly inside the 80% dev set, with the 20% test set untouched by augmentation (p. 4). Whether multiple radiographs from the same patient existed across partitions is `not reported`.

## model

- **Compared architectures:** `YOLOv8m`, `YOLOv9m`, `YOLO11m`, and `YOLO26m` (medium scale selected for accuracy-efficiency balance; Ultralytics `v8.4.x`, PyTorch `v2.14.0`, Python `v3.14.4`, pp. 3, 6).
- **Pretrained weights / exact parameter counts:** `not reported`.

## preprocessing

- **Full-OPG preparation:** Retained native JPG formats and original resolutions (`1035 × 1054` to `3292 × 1536` px). Explicitly **no manual cropping, image enhancement (no CLAHE), intensity normalization, or manual preprocessing** applied prior to pipeline input (p. 4).
- **Augmentation (dev folds only):** On-the-fly Ultralytics geometric (rotation, translation, scaling, shearing, perspective, H/V flips), photometric (HSV), mosaic, mix-up, and segment copy-paste (pp. 4–5).

## training

- **Schedule & hyperparameters (`p. 4`):** 5-fold CV, max `500` epochs with early stopping on validation loss; `5`-epoch warm-up (initial momentum `0.8`, warm-up bias LR `0.1`); batch size `64`, base LR `0.001` (increasing to `0.01`), momentum `0.937`, weight decay `0.0005`, automatic optimizer selection.

## metrics/IoU

- **Detection matching (`pp. 6–7`):** True positive for Precision, Sensitivity (Recall), and F1-score required class match AND **strict `IoU ≥ 0.80`** (chosen because boxes feed ROI cropping and FDI mapping). `mAP@0.50` computed at `IoU = 0.50`; `mAP@0.50:0.95` averaged across `0.50:0.05:0.95`. Non-parametric radiograph-level bootstrap (`2,000` iterations) used for 95% CIs; Friedman + Holm-adjusted Wilcoxon signed-rank tests used for model comparisons.
- **Segmentation metrics:** Pixel-level `mIoU` and `Mean Dice` (p. 7).

## timing/hardware

- **Training/eval workstation (`p. 6`):** Intel Core i9-12900K (3.20 GHz), 128 GB RAM, **NVIDIA RTX A5000 (24 GB GDDR6)**, Windows 11, CUDA 13.0, cuDNN 9.24.
- **Deployment & speed (`pp. 1, 6, 7, 13`):** Streamlit web UI + Docker deployed on **Google Cloud Run** (`python-docx v1.2.0` for Word report). End-to-end cloud system latency = **`15 ± 1.4 s` per panoramic radiograph** (upload through report generation). Standalone GPU inference `FPS` per detector is `not reported`.

## results with locators

- **Best overall detector (`Table 3`, pp. 8–9 — `YOLO26m` vs `YOLOv8m` / `YOLO11m` on independent test sets):**
  - *Teeth (`n=61`):* `YOLO26m` Precision `0.94`, Recall `0.94`, F1 `0.94`, `mAP@0.50 = 0.97 (0.88–0.99)`, `mAP@0.50:0.95 = 0.82` (vs `YOLOv8m` `mAP@0.50 = 0.89`, `YOLO11m = 0.96`).
  - *Periodontal bone level (`n=40`):* `YOLO26m` F1 `0.98`, `mAP@0.50 = 0.97`, `mAP@0.50:0.95 = 0.96` (Friedman `p = 0.193`, nonsignificant across YOLO versions, p. 11).
  - *Maxillary sinus floor (`n=40`):* `YOLO26m` F1 `0.96`, `mAP@0.50 = 0.94`, `mAP@0.50:0.95 = 0.83`.
  - *Dental implants (`n=52`):* `YOLO26m` Precision `0.99`, Recall `0.98`, F1 `0.98`, `mAP@0.50 = 0.97`, `mAP@0.50:0.95 = 0.89` (vs `YOLOv8m` `mAP@0.50 = 0.88`, `YOLO11m = 0.95`).
  - *Crowns (`n=39`):* `YOLO26m` F1 `0.95`, `mAP@0.50 = 0.93`, `mAP@0.50:0.95 = 0.91` (`+21.3%` over `YOLOv8m = 0.75`).
  - *Bridges (`n=34`):* `YOLO26m` F1 `0.96`, `mAP@0.50 = 0.98`, `mAP@0.50:0.95 = 0.88`.
  - *Root canal treatments (`n=66`):* `YOLO26m` F1 `0.92`, `mAP@0.50 = 0.90`, `mAP@0.50:0.95 = 0.88`.
  - *Dental fillings (`n=50`):* `YOLO26m` F1 `0.94`, `mAP@0.50 = 0.92`, `mAP@0.50:0.95 = 0.88` (Friedman `p = 0.073`, nonsignificant, p. 11).
  - *Radicular cysts (`n=16`):* `YOLO26m` Precision `0.95`, Recall `0.93`, F1 `0.94 (0.76–0.99)`, `mAP@0.50 = 0.91`, `mAP@0.50:0.95 = 0.88`.
  - *Periapical granulomas (`n=14`):* `YOLO26m` Precision `0.92`, Recall `0.90`, F1 `0.91 (0.69–0.98)`, `mAP@0.50 = 0.87`, `mAP@0.50:0.95 = 0.84`.
- **Segmentation (`Table 4`, p. 9):** `YOLO26m` achieved Mean Dice `0.97` (Teeth, Bone level, Sinus floor), `0.96` (Crowns, Bridges), `0.95` (Implants, Fillings), and `0.94` (Root canal treatments).

## limitations

- **Author-stated (`pp. 15–16`):** (1) Single-center dataset (`UZ Leuven`) without external multicenter validation; (2) very small independent test sets for periapical lesions (`16` radicular cysts, `14` granulomas) producing wide 95% CIs (`0.69–0.99`) and restricted to solitary mandibular lesions; (3) predefined target scope omits caries, impacted teeth, mandibular canal, fractured teeth, and pathological periodontal bone loss defects; (4) end-to-end tooth mapping, dental chart, and Word report were technically verified for internal variable consistency but not prospectively validated at the patient/clinical workflow level.

## critique

- High methodological rigor in separating radiograph-level test splits before ROI extraction, reporting 2,000-iteration bootstrap 95% CIs, and applying Holm-adjusted Wilcoxon tests.
- Crucial comparability caveat for our synthesis: Precision/Recall/F1 in Table 3 are evaluated at a **strict `IoU ≥ 0.80`**, whereas `mAP@0.50` uses `IoU = 0.50`; furthermore, each task was trained on a filtered subset containing only radiographs with that finding (`Table 1`), rather than a single unified multi-class detector across all 1,595 OPGs.

## reuse

- Direct architectural & deployment benchmark for **Stage `S16` (Hosted Web Demo)** — demonstrates Streamlit + Docker on Google Cloud Run with a clear research/decision-support disclaimer (`15 ± 1.4 s` end-to-end latency).
- Strong baseline comparator for `Group A` YOLO multi-generation progression (`YOLOv8m` -> `YOLOv9m` -> `YOLO11m` -> `YOLO26m`) and `G5` (high accuracy achieved on native resolutions *without* CLAHE/manual enhancement).

## conflicts

- None with project protocol; challenges any naive assumption in `G5` that manual contrast enhancement is mandatory for high YOLO detection performance on clinical OPGs.

## unresolved fields

- Standalone model-only GPU inference speed (`FPS` / ms per image) is `not reported` (only full cloud pipeline latency `15 ± 1.4 s` is given).
