## 1. Problem & Clinical / Technical Motivation
- **Clinical motivation (pp. 1–2):** Periodontitis causes progressive alveolar bone loss around tooth roots, leading to tooth mobility and tooth loss if untreated. Manual staging of radiographic bone loss (`RBL`) between the cementoenamel junction (`CEJ`) and alveolar bone crest on 2D panoramic radiographs (`OPGs`) is time-consuming and subject to high inter-observer variability.
- **Technical problem (pp. 2–4, 6–8):** Standard single-stage detectors (`YOLOv4`, `YOLOv5`, `YOLOv7`) struggle to balance fine-grained multi-scale feature extraction across `28–32` teeth per OPG with low-latency clinical inference.
- **Proposed solution (pp. 1, 4, 6–8, Fig. 3):** **`YOLOv7-M`** *(note: Abstract `p. 1` line 25 contains a typo calling it "a modified version of You Only Look Once (YOLO)v2, called YOLOv7-M")*, which modifies `YOLOv7` with:
  1. A **`Focus` (`SpaceToDepth`) stem module** slicing and concatenating spatial quarters into depth channels to reduce FLOPs/CUDA memory and speed up forward/backward passes (`pp. 6–7`).
  2. **`C3Ghost` (`GhostNet` bottlenecks)** replacing standard `C3` CSP blocks, plus a **Feature Fusion Module (`FFM`)** (`pp. 6–8`).
  3. **`ELU` (Exponential Linear Unit)** activation functions (`p. 8`).

## 2. Dataset, Annotators & Splits
- **Primary dataset provenance (`pp. 3–6, 20, Tables 2–3`):**
  - **Wuhan University Hospital of Stomatology Periodontitis Dataset (`Kong et al., 2023` — `PDCNN`):** **`1,747` anonymized panoramic radiographs** acquired using an `OC200D` unit (`Instrumentarium Dental, Inc.`) at **`1,536 × 2,976` pixels** (`p. 4`; misprinted as `15,436 × 2,976` in `Table 1`, p. 3).
  - **Public code & data links (`p. 20`):**
    - Authors' code & Zenodo archive: `https://github.com/mogragab/yolov7-m.git` and `https://doi.org/10.5281/zenodo.15565284`
    - Original `PDCNN` dataset repo: `https://github.com/PuckBlink/PDCNN`
    - Third-party Roboflow dataset also cited in Data Availability (`p. 20`): `https://universe.roboflow.com/yolo-sxtmz/teeth-gzkv1/dataset/12`
- **Annotations & class distributions (`pp. 4–6, Tables 2–3, Fig. 2`):**
  - Annotated by dental specialists in **`VGG Image Annotator (VIA)`** following the **2018 World Workshop Periodontitis Classification (`Tonetti, Greenwell & Kornman, 2018`)** across **`50,080` teeth** (unerupted third molars excluded, `p. 4`). Inter-annotator kappa (`κ`) is `not reported`.
  - **4-class Radiographic Bone Loss (`RBL`) distribution (`Table 2`, p. 6 — target task):**
    - `Healthy`: `20,175` teeth (`0.403` / `40.3%`)
    - `Mild`: `18,174` teeth (`0.363` / `36.3%`)
    - `Medium`: `8,762` teeth (`0.175` / `17.5%`)
    - `Severe`: `2,962` teeth (`0.059` / `5.9%`)
    - *Reported Total:* `50,080` *(sum of the 4 class columns in `Table 2` is `50,073`)*.
  - **3-class Furcation Involvement (`FI`) distribution (`Table 3`, p. 6 — descriptive only, not evaluated in experiments):** `Healthy = 46,532` (`92.9%`), `Mild = 2,534` (`5.1%`), `Severe = 1,014` (`2.0%`), Total `= 50,080`.
- **Dataset split & cross-validation (`p. 14, Tables 5–6`):**
  - **Hold-out split (`p. 14`):** `70%` training / `10%` validation / `20%` testing (`7:1:2` ratio). `Table 5` (`p. 14`) reports evaluation on **`4,706` tooth labels** (`Healthy = 1,753`, `Medium = 1,397`, `Mild = 1,106`, `Severe = 450`).
  - **Cross-validation (`Table 6`, p. 14):** 5-fold cross-validation across the 4 RBL severity classes.

## 5. Limitations
### 5.1 Author-Stated Limitations (`pp. 4, 6, 18–19`)
1. **Severe class imbalance (`p. 6, Tables 2–3`):** In the `50,080`-tooth dataset, `Healthy` (`40.3%`) and `Mild` (`36.3%`) RBL annotations heavily outnumber `Severe` RBL (`5.9%`, `2,962` teeth), and `Severe` furcation involvement (`FI`) represents only `2.0%` (`1,014` teeth).
2. **Subjectivity of 2D panoramic bone-level grading (`pp. 4, 18–19`):** Rotational panoramic imaging introduces geometric distortion and superimposition (`pp. 18–19`), and radiographic bone-level annotations are partially subjective across dentists (`p. 4`).
3. **Lack of clinical pocket/attachment metadata (`p. 19`):** Periodontitis staging requires clinical probing depth, attachment loss, and patient history alongside radiographs, motivating future 3D `CBCT` and multimodal/LLM integration (`p. 19`).

### 5.2 Reviewer Methodological Critique (`OS §3.2`)
1. **Mathematically impossible `F1-scores` (`F1 > max(P, R)`) in `Table 6` and `Table 7` (`pp. 1, 14–15`):** By definition (`Eq. 5`, `p. 8`: `F1 = 2PR / (P + R)`), the harmonic mean of Precision and Recall must lie strictly between `min(P, R)` and `max(P, R)`. However, in `Table 6` (`p. 14`) and `Table 7` (`p. 15`), **every single reported `F1-score` for `YOLOv7-M` is strictly higher than both `P` and `R`** (`Mean: P = 0.917, R = 0.871 -> reported F1 = 0.925` vs. true harmonic mean `0.8934`; `YOLOv7` in `Table 7`: `P = 0.721, R = 0.800 -> reported F1 = 0.874` vs. true `0.7584`). Meanwhile, `p. 9` (line 451) states that `Fig. 7`'s F1 curve peaks at **`F1 = 0.73` at threshold `0.405`**.
2. **Direct numerical contradiction between `p. 14` prose and `Table 5` (`p. 14`):** The text on `p. 14` (lines `567–575`) states that `Table 5` yielded overall **`P = 0.7, R = 0.804, mAP@0.5 = 0.81`** (`Medium P = 0.598, R = 0.728`; `Mild P = 0.653, R = 0.863`; `Severe P = 0.68, R = 0.693`), whereas `Table 5` immediately below prints **`All: P = 0.866, R = 0.891, mAP@0.5 = 0.91`** (`Medium P = 0.898`, `Mild P = 0.853`, `Severe P = 0.88` — each class precision shifted upward by `+0.20` to `+0.30` and overall `mAP@0.5` by `+0.10`). Similarly, on `p. 15` (line 678), the prose states `F1 = 0.935, mAP = 0.93` for `YOLOv7-M` while `Table 7` prints `F1 = 0.925, mAP = 0.910`.
3. **Conflation of YOLO's Precision-Confidence curve (`P_curve`) with meta-analytic `p-value` (`p < 0.05`) `p-curve` analysis (`p. 10`, lines 489–497):** On `p. 10`, the authors misinterpret Ultralytics YOLO's `P_curve.png` (`Precision vs. Confidence threshold`, `Fig. 9`) as `Simonsohn et al. (2015, 2019)`'s statistical `p-curve` (`distribution of p < 0.05 values to rule out p-hacking`). Additionally, `Eq. (1)` (`p. 8`) misprints Precision as `P = TP / (TP + FN)` (identical to Recall).
4. **Dataset discrepancy between Wuhan `PDCNN` (`1,747` OPGs, `50,080` teeth) and `Table 5` (`4,706` teeth) / Roboflow (`teeth-gzkv1`, `p. 20`):** While `Section 2` (`pp. 4–6`) describes the `1,747`-OPG Wuhan dataset (`50,080` polygons with RBL + FI), `p. 20` states the experiments used a Roboflow `teeth-gzkv1/dataset/12` bounding-box dataset, and `mAP@0.5:0.95`, parameter counts (`M`), and `GFLOPs` are `not reported`.
